# KioskBookingUjjainTemple

Self-Service Darshan Booking Kiosk for Shri Mahakaleshwar Jyotirlinga Temple, Ujjain (M.P.).

## Features
- Touchscreen-friendly self-service kiosk interface
- Real-time queue waiting time & crowd level tracking
- Fast General Darshan booking flow (Devotee count -> Name -> Slot -> Print)
- 80mm POS thermal receipt & official Darshan Pass generation with scannable QR Code
- Instant PDF Pass download support
- Bilingual (हिंदी / English) interface
